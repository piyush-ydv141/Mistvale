Mistvale Tea Co. — E-Commerce Web Application
A modern, responsive, and feature-rich single-page e-commerce web application built for Mistvale Tea Co., specializing in single-origin hill-grown teas directly from Assam and Darjeeling.

🌟 Key Features & Functionality
Dynamic Product Catalog: Filter products instantly by categories (All, Black, Green, Herbal, Gifts) and sort by price or name.

Smart Search System: Real-time simulated asynchronous product search with debounced user input.

Interactive Cart Drawer:

Full quantity management (increment/decrement/remove).

Dynamic free-shipping progress bar (Threshold: ₹499).

Coupon code validation system (WELCOME10 for 10% off on subtotal ≥ ₹399).

Pincode Serviceability Check: Regex-validated Indian pincode checker providing real-time delivery timeline estimates.

Persistent State: Uses browser localStorage to securely persist user cart items and wishlist preferences across sessions.

Quick View Modal & Wishlist: Seamlessly preview product descriptions or save favorite items with animated state changes.

🛠️ Technology Stack & Architecture
Frontend: HTML5, CSS3 (Custom properties, Flexbox, Grid), Vanilla JavaScript (ES6+).

Typography: Google Fonts (Fraunces for elegant editorial headings and Inter for clean, legible body text).

Icons & Assets: Inline SVGs for scalable, high-performance vector ratings and UI elements.

🤖 AI-Assisted Development Workflow
This project was built using an efficient, multi-step AI collaborative workflow to balance rapid prototyping with production-grade code quality:

Bug Fixing & Error Handling: Utilized AI tools to identify and resolve functional glitches, such as replacing broken form redirects with clean internal modal triggers for checkout success.

UI/UX Refinement: Improved visual alignment by standardizing product cards, integrating clean SVG-based yellow star ratings, and maintaining a cohesive warm earthy color palette (#1f3d2b, #f6f1e7, #d9962b).

Documentation & Presentation: Automatically generated comprehensive metadata, JSON-LD structured schemas, and this professional submission documentation.

🚀 Getting Started Locally
To run this project on your local machine:

Clone or download this repository.

Ensure you have the index.html file and the images/ asset directory in the same root folder.

Open index.html directly in any modern web browser (Chrome, Firefox, Edge, Safari), or run it via a local development server like Live Server in Visual Studio Code.
